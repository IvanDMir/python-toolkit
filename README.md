# python-toolkit
I´ve created this repository to store my Tools created with Python.

## Uso del script de respaldos

Desde la carpeta del repositorio, ejecuta el script indicando qué carpeta quieres respaldar:

```bash
python3 backup_folder.py .
```

El respaldo comprimido se guarda en `backups/` y los mensajes quedan registrados en `backup.log`.
